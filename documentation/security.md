# Security and limitations

- Use a dedicated test wallet, never a wallet holding valuable assets.
- Never share the private key or Secret Recovery Phrase.
- `.env` is excluded from Git; commit only `.env.example` with placeholders.
- The token supply is fixed after deployment.
- The contract uses OpenZeppelin's ERC-20 implementation.
- This educational project is not a production security audit.
- SepoliaETH and Sepolia NJT are test assets, not real-money assets.
